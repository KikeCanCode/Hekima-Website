# Hekima Voice Website

A responsive website developed for Hekima Voice, a non-profit, non-governmental organisation based in Bukoba, Kagera, Tanzania.

Hekima Voice works to protect the rights, dignity and safety of adolescent girls and young women (AGYW), promoting education, economic empowerment, child protection and sustainable development.

The website aims to improve the organisation's online presence, communicate its mission and programmes, showcase its impact, and make it easier for people to get involved.

**Tagline:** We Inspire Girls by Inspiring Change.

🌐 **Live Website:** [Visit Hekima Voice](https://hekima-voice.netlify.app/)

📂 **GitHub Repository:** [View Source Code](https://github.com/KikeCanCode/Hekima-Website)

## About the Project

This project was developed as part of my volunteer work as a Website Developer for Hekima Voice.

The goal was to create an accessible, user-friendly and responsive website that introduces the organisation, explains its work and provides visitors with ways to connect, volunteer and support its programmes.

## Website Pages
The website includes the following pages:
 
- Home: Introduction to Hekima Voice, its mission, vision, values and key programmes.

- About Us: Organisation background, history and purpose.

- What We Do: Information about the organisation's programmes and activities.

- Our Impact: Highlights of the organisation's work and achievements.

- Support Us: Information on volunteering and making donations.

- Contact Us: Contact information and an enquiry form.

- Data Protection: Information about the handling and protection of personal data.

## Running the Project Locally
This is a static website, so no backend installation or package manager is required.

1. Clone the repository:

git clone https://github.com/KikeCanCode/Hekima-Website.git

2. Open the project folder:

cd Hekima-Website

3. Open index.html in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Contact Form

The contact form uses FormSubmit to forward visitor enquiries to the organisation's designated email address.

The form includes:

- Full name

- Email address

- Phone number

- Enquiry type

- Enquiry details

The receiving email address must complete FormSubmit's initial verification before email delivery is activated.
